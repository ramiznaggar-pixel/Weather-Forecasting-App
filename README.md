# Advanced Weather Forecast Dashboard

A portfolio-quality weather website built with vanilla HTML/CSS/JavaScript.

## Features
- Live global city search
- Geolocation 
- Current conditions
- 24 hour forecast strip
- 7-day forecast
- 48 hour temperature + rain probability chart drawn with Canvas
- Wind condition visualization
- Humidity, pressure, visibility, wind gusts and direction
- Sunrise / sunset
- Rain probability insight
- Celsius / Fahrenheit switch
- Dark / light theme
- Saved favorite locations via localStorage
- Responsive layout

## Data source
The project uses Open-Meteo's Geocoding API for location search and Weather Forecast API for weather data. The forecast API supports current, hourly and daily variables, timezone-aware responses, and up to 16 forecast days; this project requests 7 days. See:
https://open-meteo.com/en/docs
https://open-meteo.com/en/docs/geocoding-api
